# 💫 About Me:
I'm Richard Mutakwa, a passionate Software Developer and aspiring Data Scientist based in Lusaka, Zambia 🇿🇲.<br>I hold a Bachelor's Degree in Information Systems and Technology from the University of Lusaka and am currently pursuing a Master's Degree in Data Science.<br>I specialize in designing, developing, and deploying full-stack applications that solve real-world problems. My experience spans software engineering, database management, API development, mobile application development, and IT infrastructure.<br>Currently, I work as a Software Developer at the University of Lusaka, where I've contributed to building and maintaining enterprise solutions, including:<br>- 🎓 Student Management Systems – Supporting academic operations and student services.<br>- 📱 Mobile Applications – Developing and deploying cross-platform applications using React Native and Expo.<br>- 👥 Human Resource Management Systems – Streamlining employee management and administrative processes.<br>- 📊 Customer Relationship Management (CRM) Systems – Improving organizational workflows and engagement.<br>- 📦 Asset Registry & Procurement Systems – Digitizing asset tracking and procurement processes.<br>- 🔗 System Integrations & REST APIs – Connecting applications and improving interoperability.
